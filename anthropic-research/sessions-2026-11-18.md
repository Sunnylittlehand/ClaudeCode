### 摘要
Claude Code v2.1.326（11 月 16 日）新增 Code Mode 与 Agent Teams 协同工作、OpenTelemetry 主机属性配置项 `OTEL_RESOURCE_INCLUDE_HOST`，以及在 Claude Code + Cowork HIPAA 配置的组织中默认启用自动模式；沙盒化命令写入的家目录范围收窄，钩子 `"decision": "block"` 覆盖范围扩大。v2.1.327（11 月 17 日）新增 `claude mcp add-json` 支持从标准输入读取 MCP JSON（防止令牌出现在命令行），VS Code 资源管理器右键菜单新增"添加到聊天"选项，`/tui classic` 命名非全屏渲染器，`/status` 列出已损坏的代理/技能/命令文件；自动模式忽略宽泛的允许规则（如 `Bash(pnpm dlx *)`），约 100 项缺陷修复，包括 `/export` 覆盖文件前不询问的问题及 `claude mcp add` 删除 `.mcp.json` 其他键值的问题。

### Summary
Claude Code v2.1.326 (November 16) introduced Code Mode working with agent teams, the `OTEL_RESOURCE_INCLUDE_HOST` environment variable for host attributes in OpenTelemetry audit logs, and auto mode defaulting on for sessions in organisations with the Claude Code plus Cowork HIPAA configuration. Auto mode now ignores broad allow rules such as `Bash(pnpm dlx *)`, tightening blast radius for auto-approved commands. Approximately 100 bug fixes including `/export` overwriting files without asking and `claude mcp add` deleting unrelated `.mcp.json` keys.

### Main Takeaway
