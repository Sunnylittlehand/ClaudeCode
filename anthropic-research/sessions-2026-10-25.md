### Significance Rating
⭐⭐⭐ — A meaningful workflow release for enterprise Codex users; the enterprise MCP sign-in and Windows proxy auth fixes in particular close gaps flagged by regulated-environment deployments.

### 摘要
OpenAI发布Codex CLI v0.164.0，新增可重用提示预设（/presets，10个插槽）、内联/model与/permissions快捷设置、企业级MCP统一登录，并修复Windows企业代理NTLM/Negotiate身份验证问题。此版本是28天冲刺计划的第12次发布。

### Summary
Codex CLI v0.164.0 introduces numbered /presets slots (up to 10) for saving and restoring reusable prompt configurations, slash commands, and session defaults — reducing repetitive setup for enterprise teams using standardised workflows. Inline /model and /permissions arguments allow developers to set model, reasoning effort, speed, and permission profiles mid-session without opening settings menus. Enterprise MCP sign-in is now managed centrally, eliminating per-user re-authentication in team environments. Windows proxy authentication now uses Negotiate/NTLM credentials from the signed-in user, resolving failures in corporate proxy environments that plagued earlier versions. Queued prompts now wait for pending permission selections to resolve before processing, preventing silent prompt loss. Image previews appear in the fullscreen transcript view. An alpha build (0.165.0-alpha.1) shipped the same day, suggesting further features are in testing.

### Main Takeaway
The enterprise MCP sign-in and Windows NTLM proxy fix mean Codex CLI v0.164.0 is the first version suitable for zero-configuration deployment in large corporate Windows environments with managed proxies.

⭐⭐⭐⭐ — This release directly addresses two of the most common friction points in enterprise Codex deployments that Sunny's bank would encounter: Windows enterprise proxy authentication (banks almost universally run authenticated HTTP proxies for egress filtering) and the need for centralised MCP sign-in management.
