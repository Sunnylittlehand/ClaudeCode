**Source**: Anthropic
**Type**: Product Update / Changelog
**Date**: 2026-08-13 to 2026-08-14
**Links**: [Claude Code changelog](https://code.claude.com/docs/en/changelog) · [GitHub releases](https://github.com/anthropics/claude-code/releases) · [Coverage: @ClaudeCodeLog](https://x.com/ClaudeCodeLog/status/2088048601154871477)

Anthropic Engineering. Covers v2.1.231 (1 change, Aug 13; MCP OAuth redirect URI fix, in ledger) plus v2.1.232 (49 changes, Aug 13–14).

### Significance Rating
⭐⭐⭐ — A broad release bringing cross-session coordination improvements and security hardening; the GitLab token redaction is a direct compliance fix for bank developer environments.

### 摘要
Claude Code v2.1.232 包含 49 项变更。核心新功能：在提示框中输入 @ 可通过名称提及其他 Claude 会话，Claude 将自动通过 SendMessage 联系该会话；子代理分叉（forking）现默认开启，继承完整对话及提示缓存；GitLab 多种 token 前缀（glrt-、gloas-等）现已自动脱敏。此外，新增 /config 中的对话过期及跨会话消息管理配置项。

### Summary
Claude Code v2.1.232 ships 49 changes. Key new features: typing `@` in the prompt lets users mention another live Claude session by name, automatically using SendMessage to reach it — enabling cross-machine agent coordination without manual session IDs. Subagent forking is now default: `subagent_type: "fork"` inherits the full conversation and prompt cache, and non-teammate agent spawns in interactive sessions run in the background by default. GitLab token prefixes (glrt-, gloas-, glptt-, glagent-, glimt-, glsoat-) are now automatically redacted from shell output and logs. New `/config` rows for dialogue expiry and cross-session message management (accept/hold/refuse per-session inbound). Sessions on the same machine now auto-assign unique names, avoiding collision when two sessions use the same name.

### Main Takeaway
The `@` cross-session mention and fork-default changes make multi-agent Claude Code coordination significantly more ergonomic — and GitLab token auto-redaction closes a credential-leakage risk for teams using GitLab CI.

### Relevance to Sunny
⭐⭐⭐ — Worth reading.
