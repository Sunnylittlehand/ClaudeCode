### Significance Rating
⭐⭐⭐ — Governance-relevant mod and code-review controls are the headline, with a meaningful security fix for worktree deletion.

### 摘要
v2.1.304新增了三个对企业部署有影响的特性：代码审查可按组织设置Quick/Standard/Deep三个级别；/auto-mode-setup命令引导式扫描项目历史以配置Auto模式；以及tool.check decider:"person"选项，要求任何Mod操作在执行前必须经过真人审批。

### Summary
Claude Code v2.1.304 introduces organisationally configurable Code Review levels (Quick, Standard, Deep) settable per repository, giving enterprise admins control over how deeply Claude audits submitted code. A new `/auto-mode-setup` command performs a guided scan of project history to train Auto Mode for a specific codebase environment. The `tool.check decider:"person"` setting requires human approval before any Mod action executes — a hard gate that complements permission prompts for compliance-sensitive deployments. A critical fix prevents `claude --worktree` from silently deleting a worktree and its branch on exit without user confirmation.

### Main Takeaway
