### 摘要
2026年7月28日，模型上下文协议（MCP）发布有史以来最重大的规范更新：将底层架构从有状态的双向会话模式改为无状态的请求/响应模式，使MCP服务器可以在无服务器或边缘基础设施上部署，大幅降低运维复杂度。认证体系全面升级为生产级OAuth 2.0与OIDC标准，与Entra、Okta等企业身份提供商实现零配置集成。同时，"应用"（Apps）与"任务"（Tasks）被纳入有版本号的官方扩展框架：Tasks由AWS贡献，支持可靠的长周期代理任务。目前MCP每月SDK下载量已达4亿次（年增4倍），Claude连接器目录已收录逾950个MCP服务器。

### Summary
The MCP 2026-07-28 specification represents the protocol's most significant architectural change since its November 2024 launch. The core change: MCP moves from a stateful, bidirectional session model to a stateless request/response protocol, enabling MCP servers to be deployed on serverless, edge, and horizontally-scaled infrastructure without session pinning. Authorization is now fully aligned with OAuth 2.0 and OIDC production standards — MCP servers can connect directly to enterprise identity systems such as Entra ID or Okta without workarounds or custom adapters. Enterprise-managed auth lets IT admins provision MCP connectors organisation-wide through their IdP, with zero-touch user setup: users inherit connector access through their existing IdP group membership at first login. Anthropic is rolling out 2026-07-28 support across all Claude products.

### Main Takeaway
MCP is now production-grade enterprise middleware: stateless, OAuth-native, and extensible — the missing infrastructure that makes scalable, governable Claude connector deployment viable for regulated institutions.
