### Speaker / Author
Anthropic Editorial. Claude Ship is a product announcement from Anthropic's Claude Code team, the same group Dario Amodei has described as the internal proving ground for the company's agentic ambitions. Anthropic reports it has been using Claude Ship on its own codebase since mid-2026.

### Significance Rating
⭐⭐⭐⭐⭐ — First AI-native PR review and approval system with branch-protection integration from a major lab; moves Claude Code from coding assistant to autonomous software-delivery agent.

### 摘要
Anthropic 发布 Claude Ship，一套由三个 GitHub 代理组成的 PR 审查与合并自动化套件：Code Review（已正式发布）、PR Steward（测试版，自动修复 CI 失败与合并冲突）和 Claude Approvals（测试版，依策略文件自主审批 PR，不绕过 GitHub 分支保护）。内部数据显示，使用 Claude Ship 后合并的 PR 数量较 2026 年 6 月至 9 月间翻倍，回滚率下降逾 40%。

### Summary
Anthropic launched Claude Ship on 23 November as a three-agent suite for GitHub pull request automation, available to Claude Team and Enterprise customers. Code Review is generally available; PR Steward (beta) auto-fixes failing checks, merge conflicts, and review comments but cannot approve or merge; Claude Approvals (beta) can approve PRs under a team-defined policy file, subject to existing GitHub branch-protection rules. Teams must explicitly make Claude Approvals a required check to enforce policy, and a rule relying on Claude's approval triggers a billed Code Review pass even in observe mode. Requires Claude Code v2.1.330+, GitHub CLI 2.63+, and git 2.38+; accessible via `/ship` command in Claude Code. Anthropic's own Claude Code team reports merged PRs more than doubled from June to September 2026 while the revert rate fell by more than 40%.

### Main Takeaway
Claude Code has shipped a production-grade PR approval layer, moving it from coding assistant to autonomous software-delivery agent at the enterprise code-review bottleneck.

## [OpenAI + Cisco Launch Shirudo — Open-Source eBPF Runtime for AI-Generated Linux Security Shields](https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m11/cisco-and-openai-launch-shirudo-a-new-project-to-safeguard-agentic-ai.html)
**Source**: OpenAI / Codex
**Type**: Product Launch (Open Source)
**Date**: 2026-11-23
**Links**: [Cisco newsroom](https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m11/cisco-and-openai-launch-shirudo-a-new-project-to-safeguard-agentic-ai.html) · [The Register](https://www.theregister.com/security/2026/11/24/cisco-and-openai-pitch-ebpf-kernel-plugins-as-the-way-to-tame-the-patchpocalypse/5311795) · [AI Weekly](https://aiweekly.co/alerts/openai-and-cisco-open-source-shirudo-an-ebpf-kernel-shield) · [MarkTechPost](https://www.marktechpost.com/2026/11/24/openai-cisco-shirudo-ebpf-linux-runtime/)

### Speaker / Author
OpenAI Editorial / Cisco Systems. Joint announcement from OpenAI and Cisco (which owns Isovalent, the company behind Tetragon, the eBPF security project Shirudo is built on). Liz Rice (Isovalent CTO) is cited in coverage as a contributor.

### Significance Rating
⭐⭐⭐ — Novel application of AI code generation to live Linux security patching without downtime; enterprise security teams will want to evaluate the operator-approval workflow before any production use.

### 摘要
OpenAI 与思科联合发布开源工具 Shirudo（BSD-2-Clause，基于 Isovalent Tetragon），允许 Codex 等 AI 代理为运行中的 Linux 系统自动生成 eBPF"防护盾"，无需重启即可临时阻断已知漏洞利用。演示中，Codex 生成的防护盾在运行中的 Elasticsearch 实例上成功拦截了 Java4Shell，激活前需操作员批准。目前处于预发布阶段，GitHub 仓库为 shirudo-dev/shirudo。

### Summary
Cisco and OpenAI released Shirudo (BSD-2-Clause, hosted at shirudo-dev/shirudo on GitHub) on 23 November as an open-source eBPF runtime that allows AI agents to generate temporary security "shields" for running Linux systems without requiring a reboot or a full patch cycle. Built on Cisco's Tetragon (from its Isovalent acquisition), Shirudo lets a Codex agent generate an eBPF program that intercepts the specific system-call path an exploit uses; a human operator must approve the shield before it becomes active. A demo showed a Codex-generated shield blocking Java4Shell on a running Elasticsearch instance without a service restart. Sources describe the project as pre-release. The stated use case is "bridge security" — buying time between vulnerability disclosure and a permanent patch deployment.

### Main Takeaway
Codex can now generate live Linux kernel security patches without downtime, with operator approval as the only human-in-the-loop requirement.

### Relevance to Sunny
⭐⭐⭐ — Relevant to Sunny's bank security posture in two ways: (1) the concept of AI-generated kernel-level patches in production environments will face significant scrutiny from bank CISOs and change-management teams — financial services typically require extensive patch validation before kernel-level changes even with a human-approval step; (2) this is competitive intelligence for the broader Codex security narrative: OpenAI is positioning Codex as a live security tool (following Codex Security in August), not just a coding assistant. Sunny should monitor whether Anthropic's Claude Code team publishes an equivalent capability.
