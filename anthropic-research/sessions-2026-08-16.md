### Speaker / Author

### 摘要
Anthropic 研究团队对 56 项美国随机对照试验进行元分析，发现现有再培训项目平均使就业率提升 2–3 个百分点、年收入增加约 1,000 美元，每位参与者成本约 13,000 美元。作者指出，若 AI 大规模取代就业，现有项目规模远不足以应对；其中"行业定向项目"（与雇主合作直接对口安置）效果最佳，但可复制性较差。建议立即扩大规模并进行严格评估。

### Summary

### Main Takeaway

**Type**: Developer SDK Release (Breaking Change)
**Date**: August 12, 2026
**Links**: [GitHub release v3.0.0](https://github.com/openai/openai-python/releases/tag/v3.0.0) · [HTTPX2 migration guide](https://github.com/openai/openai-python/blob/main/httpx2.md)

### Speaker / Author
OpenAI SDK Engineering Team. The Python SDK is the standard programmatic interface for all OpenAI API products including Codex, ChatGPT API, and the Agents SDK. v3.0.0 is a major (semver-breaking) release that requires active migration from any enterprise integration built on v2.x.

### Significance Rating
⭐⭐⭐ — A breaking SDK change that affects all enterprise Python integrations with OpenAI APIs; the TLS certificate store change is specifically relevant for bank IT environments with custom proxy and certificate configurations.

### 摘要
OpenAI Python SDK 于 8 月 12 日发布 v3.0.0，将底层 HTTP 客户端从 HTTPX 切换至 HTTPX2；httpx 不再自动安装，TLS CA 验证从依赖 certifi 改为使用操作系统信任库——这对自定义代理或容器化环境（包括银行内部网络）影响显著，因为操作系统信任库可能不包含内部 CA 证书。自定义 HTTPX 客户端、传输对象或配置对象的现有集成均需迁移，官方提供临时向后兼容逃生舱门用于平滑过渡。

### Summary
OpenAI's Python SDK v3.0.0 switches the underlying HTTP client from `httpx` to `httpx2`. `httpx` is no longer automatically installed as a dependency. The TLS certificate authority handling also changes: HTTPX2 uses the operating-system trust store rather than `certifi` — which means any enterprise environment relying on custom CA certificates (common in banks with internal certificate infrastructure or SSL inspection proxies) may experience TLS failures until the OS trust store is updated. Existing integrations using custom HTTPX clients, transports, or config objects must be migrated to HTTPX2 equivalents using the published migration guide. A temporary legacy escape hatch exists for gradual migration. The runtime minimum is Python 3.10; Node.js 22 minimum was enforced simultaneously in the Node SDK (v7.0.0).

### Main Takeaway
Any bank team running OpenAI API integrations via the Python SDK must audit their TLS certificate configuration and dependency pinning before upgrading to v3.0.0.

### Relevance to Sunny
⭐⭐⭐ — Worth flagging to Sunny's bank IT architecture team. If any developer teams are using the OpenAI Python SDK (for Codex API access, ChatGPT API, or evaluation workflows), this breaking change requires an active migration. The TLS CA change is the highest-risk element: UK bank environments typically run SSL inspection proxies and have internal CA hierarchies; if the OS trust store does not include those CAs, all HTTPX2-based OpenAI SDK calls will fail with TLS errors after upgrade. Recommend the bank's API management team pin to v2.x until they can test the TLS behaviour in their network environment.

## [Andrej Karpathy — "Karpathy's Pelican" AI Animation Benchmark](https://news.ycombinator.com/item?id=49140998)

**Type**: Research / Benchmark Release
