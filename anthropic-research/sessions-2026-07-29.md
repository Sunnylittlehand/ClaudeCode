### Significance Rating
⭐⭐⭐⭐⭐ — Eliminates stateful sessions, adds private-network tunnels and production-grade OAuth/OIDC alignment: directly reshapes how Claude Code and Claude Apps connect to enterprise systems in a regulated environment.

### 摘要
MCP 2026-07-28 规范正式发布，是 MCP 自发布以来最大的一次更新。协议从有状态双向模式彻底切换至无状态请求/响应架构，消除了 initialize 握手和 Session ID，每个请求均自包含。新增"多轮请求（MRTR）"机制，支持在无状态上下文中途请求用户确认；HTTP 头路由（Mcp-Method / Mcp-Name）允许网关和限速器无需解析 JSON 即可路由流量。授权层与 RFC 9207 对齐，正式废弃动态客户端注册（DCR），改用客户端 ID 元数据文档（CIMD），并绑定凭证到颁发服务器——对接 Entra ID 和 Okta 无需再绕过。"MCP 隧道（研究预览）"允许 Claude 连接私有网络内的 MCP 服务器，无需开放任何公网端口或 IP 白名单，对金融机构极具价值。Tasks 和 MCP Apps 升级为正式版本化扩展。所有 Tier 1 SDK（TypeScript、Python、Go、C#）以及 Rust Beta 均已更新，Roots/Sampling/Logging 进入 12 个月弃用窗口。

### Summary
The MCP 2026-07-28 specification — published July 28, 2026 — is the protocol's most significant revision since launch and has landed alongside a Claude blog post confirming how Claude and Claude Code will adopt it. The core change drops the stateful session model entirely: every request is now self-contained, carrying its protocol version and client capabilities in `_meta`, enabling deployment behind standard round-robin load balancers with no sticky sessions or shared session store. Multi Round-Trip Requests (MRTR) preserve mid-call user confirmation flows — servers return `resultType: "input_required"` and clients retry with responses attached — so human-in-the-loop approval gates still work in a stateless context. Authorization is hardened to production OAuth 2.0 / OIDC: RFC 9207 issuer validation is mandatory, Dynamic Client Registration (DCR) is formally deprecated in favour of Client ID Metadata Documents (CIMD), and credentials are bound to their issuing server — meaning Claude Code can authenticate to Entra ID or Okta without workarounds. MCP Tunnels (research preview) let Claude reach MCP servers inside a private network without any inbound firewall rules, public endpoints, or IP allowlisting on the origin. Tasks and MCP Apps formally graduate into versioned extensions (`io.modelcontextprotocol/tasks`), giving enterprises a stable extension path. Cacheable list results (`ttlMs`, `cacheScope`) reduce redundant fetches. MCP has 400M monthly SDK downloads (4× this year) and 10,000+ servers.

### Main Takeaway
MCP is now stateless, production-grade, and enterprise-ready — with private network tunnels that could change how regulated firms deploy Claude agents behind their firewall.
