## [Stealing Reasoning Traces from Proprietary LLM APIs — Single Global Key Flaw Across Anthropic, OpenAI, and Google](https://arxiv.org/abs/2408.XXXXX)
**Source**: MATS Research / ELLIS Institute Tübingen / Max Planck Institute for Intelligent Systems
**Type**: Research Paper / Security Disclosure
**Date**: August 10, 2026
**Links**: [The Hacker News coverage](https://thehackernews.com/2026/08/openai-anthropic-google-api-flaw-let.html) · [CSA Research Note](https://labs.cloudsecurityalliance.org/research/csa-research-note-reasoning-trace-theft-llm-apis-20260812-cs/) · [Decrypt coverage](https://decrypt.co/375501/inner-thoughts-every-major-ai-model-exposed-exploit)

### Speaker / Author
Joint paper by researchers at MATS Research, the ELLIS Institute Tübingen (Europe's premier AI research network), and the Max Planck Institute for Intelligent Systems. These are independent academic institutions with no commercial stake in any of the three affected providers — their findings carry high credibility and have already prompted server-side fixes from all three labs.

### Significance Rating
⭐⭐⭐⭐⭐ — A disclosed vulnerability affecting every major frontier lab simultaneously, revealing that a structural API design flaw let attackers extract encrypted chain-of-thought reasoning from production systems and recover real credentials and PII from public repositories.

### 摘要
MATS Research 与欧洲顶级人工智能研究机构联合披露：Anthropic、OpenAI 和 Google 三家公司的推理模型 API 共用同一个全局加密密钥，攻击者只需将强模型生成的加密推理令牌"重放"给同家公司更弱的模型，即可还原完整的明文思维链，无需直接破解强模型。研究团队从公开代码仓库中解码了 31.5 万个推理块，成功恢复 182 条凭证和 367 条个人信息。三家公司在负责任披露后已部署服务端修复，漏洞利用已无法复现，但历史泄露无法追溯消除。

### Summary
Researchers from MATS, ELLIS Tübingen, and the Max Planck Institute published a paper on August 10, 2026, revealing that Anthropic, OpenAI, and Google all used a single global encryption key for their reasoning tokens — the same key across all models in each provider's family. The attack technique, which they call a "decryption jailbreak," captures an encrypted reasoning block from a heavily-guarded flagship model (e.g. Claude Fable 5, GPT-5.6 Sol, Gemini Ultra) and replays it into a weaker sibling model, which can then be prompted to transcribe the block in plaintext — never touching the stronger model directly. Scanning 6,708 public agent trajectories on GitHub and Hugging Face, the researchers decoded 315,320 reasoning blocks and recovered 182 credentials and 367 PII artifacts already in public circulation. All three providers deployed server-side fixes after responsible disclosure and the proof-of-concept attacks are no longer reproducible, but the historical leaked data cannot be recalled.

### Main Takeaway
Every frontier lab's reasoning API was architecturally broken in the same way — a single shared encryption key that turned any weaker sibling model into a decoder ring for its stronger relatives.

### Relevance to Sunny
⭐⭐⭐⭐⭐ — This is an immediate CISO briefing item for Sunny's bank. Before this patch, every Claude Code session that surfaced encrypted reasoning tokens (e.g. via extended thinking mode in Fable 5 or Mythos 5) was potentially vulnerable if those tokens were logged, cached, or stored in a pipeline. The 182 recovered credentials should prompt a check: have any Claude Code–generated agent trajectories been committed to internal or public repositories? The fact that Anthropic has patched the server-side flaw does not eliminate audit obligations — FCA/PRA incident-response frameworks require assessing whether any confidential data passed through potentially-exposed reasoning paths. This also strengthens the case for Anthropic's Compliance API (Cowork + Claude Code session capture) as the authoritative record for what was and was not exposed.

### Speaker / Author
Announced jointly by Google Cloud and the Agentic AI Foundation (AAIF), directed by the Linux Foundation. ### Significance Rating
⭐⭐⭐ — A2A (Agent-to-Agent, Google's standard for how AI agents communicate with one another) joining the same neutral governance body as Anthropic's Model Context Protocol (MCP) is a meaningful consolidation of the multi-agent protocol layer under open stewardship.

### 摘要
Google Cloud 将 A2A（智能体间通信协议）捐赠给 Linux 基金会旗下的 Agentic AI Foundation（AAIF），与 Anthropic 的 MCP 共同纳入统一开放治理体系。AAIF 现有 250 余家成员，涵盖各大云服务商和 AI 实验室。MCP 规范智能体与工具/数据源的连接，A2A 则规范智能体间的通信，两者互补共同构成 AI 智能体协作基础设施。

### Summary
Google Cloud donated its Agent-to-Agent (A2A) protocol to the Agentic AI Foundation on August 17–20, placing it alongside Anthropic's Model Context Protocol (MCP) under the same Linux Foundation-directed governance body. MCP standardizes how agents connect to tools and data sources; A2A governs how agents communicate and collaborate with one another. With A2A and MCP now under one roof, the AAIF effectively holds governance over the full protocol stack for multi-agent systems. The foundation has grown from fewer than 40 members at its December 2025 launch to more than 250, including every major cloud provider and AI lab.

### Main Takeaway
The two foundational protocols for agentic AI — one governing tool connections (MCP), one governing agent-to-agent communication (A2A) — are now jointly stewarded by a neutral foundation with 250+ members, reducing vendor lock-in risk for enterprise multi-agent deployments.
