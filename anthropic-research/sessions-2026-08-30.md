Codex CLI v0.150.0（2026年8月26日稳定版）新增 Interrupt 钩子事件——当正在执行的顶层任务被中断时触发脚本或 MCP 处理程序，这是一个新的企业治理控制点；同时引入 /copy 全响应选择器、任务 @ 提及（可从终端直接寻址），以及支持终端的 Markdown 可点击链接渲染。安全方面，macOS 发布包改为通过 Azure Key Vault 完成公证签名，不再导出私钥。v0.150.1（8月27日）为纯缺陷修复补丁。

### Summary
Codex CLI v0.150.0, released August 26 as a stable build, adds four notable capabilities: an Interrupt hook event that fires scripts or MCP handlers when an active top-level turn is interrupted (enabling enterprise-controlled response to user task cancellations); a `/copy` command that opens a picker covering the full session response rather than just the last turn; task @mentions that make Codex sessions addressable from the terminal; and Markdown link rendering as clickable labels in supported terminals. The previous stable was v0.149.0 (August 20).

### Main Takeaway

Claude Code's parallel track (v2.1.222→v2.1.251 over the same period) continues to lead on enterprise features (--restricted mode, Compliance API, PreModelSwitch, Inference Hooks), but the CLI usability gap is closing.
- **Claude's scientific ambitions are institutional.** MHS, AI for Science seats, and the protein design research all point to Anthropic building a distinct scientific platform track alongside the enterprise-software track. This matters for banks because scientific computing (quantitative research, risk modelling, simulation) is where the next wave of Claude Code adoption is likely to come, and Anthropic is purposefully building for it.
