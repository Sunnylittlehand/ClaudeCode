## [Anthropic Python SDK v1.0.0 — httpx2 Migration and Breaking Changes](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.0.0)
**Source**: Anthropic
**Type**: Platform / SDK Update
**Date**: 20 August 2026 *(missed in prior sessions — covering today)*
**Links**: [GitHub Release](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.0.0) · [Migration Guide](https://github.com/anthropics/anthropic-sdk-python/blob/v1.0.0/MIGRATION.md)

### Speaker / Author
Anthropic Developer Platform Team.

### Significance Rating
⭐⭐⭐ — v1.0.0 ships several breaking changes including an httpx → httpx2 migration and a TLS CA shift to the OS trust store; the latter carries specific risk for enterprise environments with SSL-inspection proxies — the same concern raised by the OpenAI Python SDK v3.0.0 (covered Aug 12).

### 摘要
Anthropic Python SDK v1.0.0（2026 年 8 月 20 日）引入重大突破性变更：HTTP 层从 httpx 迁移至 httpx2（自定义 HTTP 客户端须从 httpx2 重建），TLS CA 由 certifi 改为操作系统信任库（对企业 SSL 检查代理影响较大），移除 Text Completions API 及 Messages 方法上的 `temperature`/`top_p`/`top_k` 废弃参数，要求 Python 3.10+，Bedrock 客户端未配置区域时现直接报错而非默认 `us-east-1`。

### Summary
The Anthropic Python SDK v1.0.0 (released August 20, 2026 — missed in prior reports) ships four breaking changes relevant to enterprise deployments: (1) HTTP layer migrates from **httpx** to **httpx2** — custom `http_client`, `Timeout`, and transport objects must be rebuilt from `httpx2`; (2) TLS CA source shifts from certifi to the **OS trust store** — high-risk for environments with SSL-inspection proxies (Zscaler, Netskope, Palo Alto), identical to the concern raised by OpenAI SDK v3.0.0 (covered Aug 12); (3) Legacy Text Completions API and deprecated `temperature`/`top_p`/`top_k` parameters on Messages removed; (4) `AnthropicBedrock` now raises an error when no AWS region is configured rather than defaulting to `us-east-1`. Python 3.10 minimum.

### Main Takeaway
Enterprise teams using the Anthropic Python SDK must test httpx2 compatibility and validate OS-trust-store TLS behaviour against their corporate proxy before upgrading.

### Relevance to Sunny
⭐⭐⭐ — The OS trust store change is a real-world blocker in corporate SSL-inspection environments — exactly the setup most investment banks run. Any Claude Code integration using the Python SDK (custom MCP servers, pipeline scripts, internal tooling) needs staging validation before upgrading. Follow the same procedure as for the OpenAI SDK v3.0.0 migration: explicitly configure the CA bundle path (`REQUESTS_CA_BUNDLE` / `SSL_CERT_FILE`) and run end-to-end in non-production first. Assign this sprint; v1.0.0 is now 3 weeks old.
