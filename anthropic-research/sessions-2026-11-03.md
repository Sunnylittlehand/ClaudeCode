### 摘要
2026年10月29日，Cursor扩展市场上的Claude Code官方扩展（v2.1.313）遭遇供应链攻击，恶意版本在线约11小时（太平洋时间2:27至13:35），影响最多5,000名开发者。攻击者劫持发布者访问令牌后植入SSH反向隧道和持久化脚本，可窃取主机名、用户名、Git邮件、环境变量及公网IP等系统元数据，并在删除扩展后仍可保持访问权限。Anthropic确认其自身系统未受波及；安全版本为v2.1.314。CVE编号CVE-2026-31854。

### Summary
On October 29, a trojanized build of the Claude Code Cursor extension (v2.1.313) was live on the Cursor marketplace for approximately 11 hours, affecting up to 5,000 developer machines. The malicious payload exfiltrated system metadata — hostnames, usernames, OS details, environment variables, Git email addresses, and public IP addresses — and attempted to establish SSH reverse tunnels for persistent privileged access. Critically, deleting the extension may not be sufficient: the payload drops standalone persistence scripts that run independently of Cursor, meaning affected machines should be treated as fully compromised and all credentials rotated. Attribution is unclear; the most likely vector is a stolen or abused publisher access token for the Cursor marketplace account. Anthropic confirmed its own systems, employee laptops, and official distribution channels were not compromised. The safe version is v2.1.314.

### Main Takeaway
A developer's most-trusted tool became the attack vector: the Claude Code supply chain was compromised at the IDE marketplace layer, not at Anthropic itself, exposing a gap that enterprise security policies must now close.

### Summary

Some developers report false positives on legitimate original work. No formal usage-policy update has been published, and the boundary between a genre game and a named clone remains ambiguous.

### Main Takeaway
