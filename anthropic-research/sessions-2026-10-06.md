Anthropic Product. This is a platform-wide infrastructure change to how Cowork tasks are executed, not a feature release.

### Significance Rating

### 摘要
Anthropic于10月6日宣布，Claude Cowork的计算任务将从本地设备迁移至Anthropic的云端服务器，首批适用对象为Pro和Max用户。原"仅在您的电脑上运行"选项已从设置中移除。迁移后，即使笔记本电脑关闭，Cowork任务仍可持续运行；Web端和移动端的Beta版本也将同步提供。对于企业部署而言，此次架构变更意味着所有Cowork代理活动（包括可能涉及代码、文档或内部数据的任务）均在Anthropic服务器上处理，而非用户本地机器。部分功能（本地文件、本地MCP服务器、Chrome中的Claude、计算机使用功能）仍需桌面应用保持开启状态。

### Summary
Starting October 6, Claude Cowork tasks for Pro and Max subscribers run on Anthropic's cloud infrastructure rather than the user's local machine. The "Only on your computer" toggle has been removed from Settings. The practical benefits are that tasks continue when the laptop is closed, and Cowork is now accessible on web and mobile in beta. The compliance implication is significant: any data processed by a Cowork agent — code, documents, internal business data passed through prompts — now runs on Anthropic's servers. Some capabilities remain desktop-dependent (local files and folders, local MCP servers, browser use via Claude in Chrome, and Computer Use), so full cloud-only operation requires Anthropic-managed data sources. Desktop users retain a local-processing option.

### Main Takeaway
Cowork's move to Anthropic's cloud means regulated-industry deployments must now treat Cowork agent activity as cloud-processed data — not on-device — and review their data classification and DLP policies accordingly.

⭐⭐⭐⭐☆ — This is an immediate governance action item. This change affects data-residency assurances: prior assessments that relied on "runs on the developer's local machine" are no longer accurate. Sunny should check: (1) whether the bank's approved data classification for Claude Code extends to cloud-executed agent runs; (2) whether the Enterprise Frontier Safeguards (EFS) tier, which keeps data in enterprise-managed cloud, applies to Cowork or only to direct API calls; (3) whether the Data Processing Addendum (DPA) and any FCA/PRA SS2/21 third-party data-access notification obligations need to be updated.
