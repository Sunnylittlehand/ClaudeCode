### 摘要
Claude Code v2.1.277将Bedrock、Vertex、Foundry及遥测禁用环境升级为默认使用MCP v2客户端和2026-07-28协议规范。/code-review命令改为对无自定义调优的模型使用更精简的内联审查提示，而非生成大量子代理。type:sdk类型的MCP条目现在将被跳过并显示警告，本地会话的制品监听行为也有所调整。

### Summary
Claude Code v2.1.277 promotes MCP v2 client and the 2026-07-28 protocol negotiation to default for Bedrock, Vertex, Azure Foundry, and telemetry-disabled installs. Artifact watching behaviour in local sessions has been adjusted so a new version published from another session no longer initiates a turn. Plugin and marketplace clones now leave Git LFS files as pointers instead of downloading them, reducing clone time for large repos.

### Main Takeaway
MCP v2 is now the default protocol on all major cloud-hosted Claude Code environments — enterprises on Bedrock/Vertex/Foundry should confirm their MCP server configurations are v2-compatible.
