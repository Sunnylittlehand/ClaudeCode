## [Auto Mode Is Now the Default in Claude Code for Pro, Max, and Team Plans](https://claude.com/blog/auto-mode-default-in-claude-code)
**Source**: Anthropic
**Type**: Product Update / Blog Post
**Date**: 2026-08-09 (effective 2026-08-14)
**Links**: [Official blog](https://claude.com/blog/auto-mode-default-in-claude-code) · [Configure auto mode docs](https://code.claude.com/docs/en/auto-mode-config) · [TechCrunch coverage](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) · [The New Stack analysis](https://thenewstack.io/claude-code-auto-mode/)

### Speaker / Author
Anthropic Editorial. This announcement comes directly from the Claude Code product team and is accompanied by a study of 1,053 paid users plus independent validation from Trajectory Labs.

### Significance Rating
⭐⭐⭐⭐⭐ — A fundamental shift in Claude Code's default permission model, backed by hard data on human failure rates, with explicit enterprise carve-outs and immediate token-cost implications.

### 摘要
Anthropic 宣布自2026年8月14日起，将 Pro、Max 和 Team 计划的 Claude Code 自动切换为"auto 模式"作为默认权限设置。该模式内置分类器，能拦截不可逆或有破坏性的操作，实验数据显示其拦截危险命令的成功率为89%，而人工审核仅为13.6%。企业版、API 及各云平台暂不强制切换，留给管理员评估时间。分类器产生的额外 token 费用即日起免除。

### Summary
Starting 14 August 2026, new Claude Code sessions on Pro, Max, and Team plans will run in auto mode by default — instead of asking for human approval at every step, a classifier routes every action and blocks anything deemed irreversible, destructive, or aimed outside the user's environment. A study of 1,053 paid testers found humans refused dangerous commands only 13.6% of the time (dropping to ~5% late in long sessions), versus 89% for auto mode. Separately, Trajectory Labs ran 720 indirect prompt injection attacks against Fable 5, Opus 5, and Sonnet 5 running auto mode: none succeeded. Enterprise, API, Bedrock, Google Cloud, and Microsoft Foundry deployments remain opt-in, giving admins time to evaluate and set org defaults. The classifier's per-tool-call token overhead is no longer billed to users, effective immediately.

### Main Takeaway
Humans are statistically unreliable approvers for AI coding agents — Anthropic is automating the safety layer, and enterprise admins now have a concrete window to set their own defaults before August 14 propagates to all Pro/Max/Team users.

### Relevance to Sunny
⭐⭐⭐⭐⭐ — Must-read and time-sensitive. Your developer teams on Pro and Max plans will see auto mode switch on automatically on August 14 unless you act first — audit their current permission mode now. Enterprise accounts are explicitly opt-in (unchanged), which gives you time to evaluate before mandating it bank-wide; this is the correct rollout posture for a regulated environment where every autonomous action needs a defensible audit trail. The 89%-vs-13.6% data is a powerful internal argument for standardising on auto mode across all team tiers once your security team has reviewed the classifier's scope. The Trajectory Labs prompt-injection result (720 attacks, 0 successes) also provides external validation that can support your FCA third-party risk documentation.

- **The Karpathy signal.** Karpathy (now Anthropic pre-training lead) publicly framed Claude Opus 5's 3D world-building as proof that LLMs have moved "beyond simple prompts" into compositional engineering.
