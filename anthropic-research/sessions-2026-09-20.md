## [Claude Code v2.1.278 — Auto Mode Server Classifier as Default, AGENTS.md Support](https://code.claude.com/docs/en/changelog)
**Source**: Anthropic
**Type**: Product Update / Changelog
**Date**: 2026-09-19
**Links**: [Changelog](https://code.claude.com/docs/en/changelog) · [Auto mode billing docs](https://code.claude.com/docs/en/auto-mode-classifier-billing)

### Speaker / Author
Anthropic Engineering. Claude Code is Anthropic's agentic coding assistant CLI and desktop app, the product Sunny is rolling out to developer teams at her bank.

### Significance Rating
⭐⭐⭐ Auto mode's new server-side classifier default eliminates billing overhead for the majority of Enterprise deployments; AGENTS.md cross-vendor standardisation is a quiet but meaningful interoperability step.

### 摘要
Claude Code v2.1.278将自动模式分类器默认切换至服务器端运行，消除了API和企业用户的分类器计费开销；同时新增AGENTS.md支持（当项目中无CLAUDE.md时自动读取），促进多编码工具互操作；新增/status面板中的"Auto mode server"状态行，便于合规审计追踪。

### Summary
Claude Code v2.1.278 switches the auto mode safety classifier to server-side by default for API, Enterprise, Bedrock, Vertex, Foundry, and gateway deployments — ending the extra per-token billing overhead that previously applied when classifier overhead was charged to customers. Projects without a `CLAUDE.md` now automatically fall back to reading `AGENTS.md`, aligning Claude Code's project-instruction convention with Codex CLI (which also uses `AGENTS.md`) and reducing friction for teams using both tools. A new "Auto mode server" status row in `/status` makes it straightforward to confirm which classifier is in use per session.

### Main Takeaway
Enterprise deployments get a cost reduction and AGENTS.md cross-compatibility in one maintenance release.

### Relevance to Sunny
⭐⭐⭐ The auto mode billing change is a direct cost-management win for Sunny's enterprise deployment — no configuration change required, the saving is automatic for API/Enterprise installs. The AGENTS.md fallback is relevant if her developer teams also use Codex CLI: a single AGENTS.md can now drive both tools' project-context behaviour, reducing configuration duplication. The new `/status` server-classifier row is useful evidence in any compliance audit trail showing how session behaviour is governed.
