## [Claude Enterprise Inference Hooks: Real-Time DLP Enforcement on Every Prompt, Across Every Surface](https://claude.com/blog/claude-enterprise-inference-hooks)
**Source**: Anthropic
**Type**: Product Update / Blog Post
**Date**: 2026-08-05
**Links**: [Anthropic blog](https://claude.com/blog/claude-enterprise-inference-hooks) · [Platform docs](https://platform.claude.com/docs/en/manage-claude/inference-hooks) · [Unite.AI coverage](https://www.unite.ai/anthropic-puts-inline-data-loss-prevention-inside-claude-enterprise/) · [Zscaler integration](https://jacksonholdingcompany.com/zscaler-integrates-with-claude-inference-hooks-to-scale-ai-while-addressing-risks-ashwin-kesireddy-zscaler/)

### Speaker / Author
Anthropic Editorial — the product and engineering teams behind Claude Enterprise. The announcement builds on the June 2026 Claude Compliance API (28 integrations), extending DLP coverage from conversation logs to the inference call path itself.

### Significance Rating
⭐⭐⭐⭐⭐ — The single most consequential enterprise security feature Anthropic has shipped for regulated-industry buyers: for the first time, every prompt sent to Claude in any Enterprise surface is routable through the organisation's own DLP/SASE server for an allow-or-deny verdict before the model processes it.

### 摘要
Anthropic 于8月5日为企业版Claude推出「推理钩子」（Inference Hooks）测试版，打造覆盖聊天、Claude Code、Claude Cowork等全部企业端口的单一内联DLP拦截层。每条提示词在到达模型前，均通过企业自有安全服务器（Netskope、Zscaler、Palo Alto Networks、Proofpoint均已集成）进行放行或拦截判断。当前版本仅在提示词入参侧拦截，模型返回侧的审查计划在后续推出。值得注意的是，该功能仅适用于Claude Enterprise界面，不涵盖通过Claude平台API直接访问或经Amazon Bedrock、Google Cloud部署的场景。

### Summary
Anthropic launched inference hooks in beta on August 5 as an enterprise-grade DLP enforcement layer that routes every employee prompt through the organisation's own security server for an allow-or-deny verdict before Claude ever processes it. The protocol is webhook-based with a published schema, covering all Claude Enterprise surfaces: chat, Claude Code, and Claude Cowork in a single configuration. Launch partners include Netskope, Zscaler, Palo Alto Networks, and Proofpoint; in-house security servers are also supported. At launch the hook fires on the incoming prompt only — response-side enforcement (checking what Claude returns) is on the roadmap. Critically, the feature is scoped to Claude Enterprise surfaces; direct Claude Platform API usage, Bedrock deployments, and Google Cloud deployments are out of scope at this stage.

### Main Takeaway
Anthropic has moved enterprise DLP from post-hoc logging to pre-inference interception — every prompt, every surface, one webhook, stopping sensitive data before the model sees it.

### Relevance to Sunny
⭐⭐⭐⭐⭐ — This is the answer to the question every bank CISO and DPO asks before approving Claude Code: "how do we stop an employee submitting a client name, deal terms, or MNPI to the model?" Inference hooks closes that gap with a single enforcement layer that plugs into the DLP stack the bank already runs (Zscaler or Netskope are common across UK investment banking). The fact that it covers Claude Code means developer sessions are subject to the same pre-inference controls as chat — which removes one of the key arguments for restricting developer access. Important caveats for Sunny's planning: (1) this is Claude Enterprise only, so any teams accessing via Bedrock or Google Cloud must be migrated or kept out of scope; (2) response-side enforcement is not yet available, meaning a model could still return sensitive content reconstructed from non-sensitive inputs — the control is at the prompt boundary only; (3) this is still beta, so Sunny should run a pilot with her CISO and the preferred DLP vendor before citing it in regulatory conversations. For a bank looking to broaden Claude Code access from a small piloted group to broader developer populations, this is the governance unlock.
