**Source**: Anthropic
**Type**: Product Update / Developer Platform
**Date**: 2026-08-07 (missed in prior sessions)
**Links**: [Platform Docs — Session Budgets](https://platform.claude.com/docs/en/managed-agents/budgets) · [Managed Agents Overview](https://platform.claude.com/docs/en/managed-agents/overview)

### Speaker / Author
Anthropic Platform Team. This is a Developer Platform release, shipped August 7 alongside Claude Code Week 38 (v2.1.224), but missed in the prior August 7 session which focused on Claude Code and Claude Enterprise consumer features.

### Significance Rating
⭐⭐⭐⭐ — First-party hard spend cap for Managed Agent sessions closes the most significant cost-governance gap in Anthropic's agentic API; directly reduces financial runaway risk and enables bank IT to define maximum cost per automated agent session without relying on external API-key throttling.

### 摘要
Anthropic 开发者平台新增"会话预算"功能：可为每个 Claude Managed Agents 会话设定硬性美元上限（以美分为单位），超出后会话以 budget_reached 状态暂停，而非继续发起模型请求；修改或移除预算即可恢复会话。预算在会话创建时通过 max_list_cost 字段设定，通过 Deployment 配置可将同一预算应用于所有由该 Deployment 启动的会话。该功能于 8 月 7 日上线，与 Claude Code v2.1.224 同期推出，但在此前日报中遗漏。计费单价采用 Anthropic 公开标准价，不加价。

### Summary
Anthropic's Developer Platform now allows operators to set a hard dollar cap on any Claude Managed Agents session via a `max_list_cost` field (amount in US cents as a string, currency USD). A session that reaches its budget pauses with the `budget_reached` stop reason instead of starting new model requests — the agent suspends cleanly rather than failing or overrunning. Changing or removing the budget resumes the session. Deployments can set the same budget field, applying it automatically to every session they start. Pricing is at standard Anthropic public list rates with no markup. Sessions are charged $0.08/hour plus token costs at standard per-model rates.

### Main Takeaway
Anthropic now lets operators cap agent spend at the API level — closing the most-requested cost-governance gap for agentic enterprise deployments.

Without a first-party spend cap, runaway agent loops create unbounded cost exposure — a clear financial control failure that bank audit committees flag in any AI system assessment. The `budget_reached` pause-and-resume design is particularly audit-friendly: it creates a deterministic record of the cost event rather than an error, and the session can be resumed under human review. Sunny should specify this feature in the bank's Claude Code technical requirements and test it during the enterprise pilot.
