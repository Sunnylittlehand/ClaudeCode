**Source**: Anthropic
**Type**: Product Changelog
**Date**: 2026-11-06

### 摘要
Claude Code v2.1.319（11月6日）：Auto mode不再回退至内置本地分类器，默认仅依赖服务端判断；关闭遥测或功能标志时，无法服务器端校验的调用将改为询问或拒绝，而非静默通过。可通过设置`CLAUDE_CODE_AUTO_MODE_SERVER=0`恢复旧行为（Bedrock/Vertex/Foundry不受影响）。同版本还支持MCP任务在终端运行，长时间工具调用自动移入后台执行。

### Summary
Claude Code v2.1.319 (November 6) removes the auto mode fallback to the built-in local classifier: when telemetry or feature flags are off, calls the server cannot evaluate are now asked about or denied rather than silently permitted. Setting `CLAUDE_CODE_AUTO_MODE_SERVER=0` restores the previous classifier behaviour; Bedrock, Vertex AI, and Foundry deployments are unchanged. The same release adds MCP task support in the terminal, with long-running tool calls automatically moved to the background.

### Relevance to Sunny
