## [OpenAI: Two API Settings Tripled GPT-5.6 Sol's ARC-AGI-3 Score (13.3% → 38.3%)](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)
**Source**: OpenAI
**Type**: Research / Benchmarking
**Date**: 2026-07-30
**Links**: [OpenAI post](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/) · [OfficeChai](https://officechai.com/ai/openai-says-gpt-5-6s-score-on-arc-agi-3-tripled-after-turning-on-two-api-settings/) · [GIGAZINE](https://gigazine.net/gsc_news/en/20260731-how-enabling-two-settings-tripled-arc-agi-3-benchmark/)

### Speaker / Author
OpenAI Research. ARC-AGI-3 is a frontier benchmark designed by François Chollet to test genuine generalisation ability (not pattern memorisation). Achieving 38.3% places GPT-5.6 Sol at roughly state-of-the-art for this benchmark.

### Significance Rating
⭐⭐⭐ — The result matters less for the raw score than for the methodological lesson: benchmark comparisons across AI models are unreliable unless inference settings (retained reasoning, compaction, context management) are controlled — an important caveat for enterprise buyers evaluating AI models on published leaderboards.

### 摘要
OpenAI 发现，GPT-5.6 Sol 在 ARC-AGI-3 基准上的得分，仅通过启用两项已在 ChatGPT 和 Codex 中使用的 API 设置（保留推理 + 上下文压缩），即可从 13.3% 跃升至 38.3%，同时输出 token 用量减少约 6 倍。标准评测框架在每步操作后丢弃了模型的推理轨迹，并随着上下文填满而截断早期操作记录，导致模型每次都要从头开始；OpenAI 的设置则维持了跨步骤的推理一致性。

### Summary
OpenAI published an analysis showing that GPT-5.6 Sol's score on ARC-AGI-3 nearly tripled — from 13.3% to 38.3% — simply by enabling two API settings already used in production inside ChatGPT and Codex: **retained reasoning** (keeping the model's chain-of-thought across moves) and **compaction** (summarising earlier context rather than dropping it). The standard ARC-AGI-3 harness discarded the model's reasoning after each action and truncated the context as it filled, forcing the model to restart from scratch on every step. With the settings enabled, the model uses approximately 6× fewer output tokens per puzzle. OpenAI claims this makes GPT-5.6 Sol state-of-the-art on ARC-AGI-3.

### Main Takeaway
Benchmark scores for AI models are meaningless unless inference-time reasoning settings are matched to real-world deployment conditions — the same model can triple its score by enabling two settings already used in production.

### Relevance to Sunny
⭐⭐⭐ — Useful context for Sunny's model evaluation methodology. When developer teams or vendors present AI benchmark scores, the inference harness matters as much as the model; insist that pilot evaluations for Claude Code and Codex use production-equivalent settings, not default harness configurations. This is particularly important for any formal vendor assessment submitted to the bank's model risk function — document the inference settings used alongside the benchmark scores.
