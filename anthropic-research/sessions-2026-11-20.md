### Speaker / Author
Anthropic Editorial. The Claude Platform team, launched as part of Anthropic's broader Claude developer ecosystem alongside the IPO. This billing model is specifically targeted at SaaS developers building on top of Claude who want to pass through token costs to their enterprise customers.

### Significance Rating
⭐⭐⭐ — A material developer-platform feature with a key enterprise security implication: requests still run in the platform's organisation, so the customer's IP allowlists and data-residency controls do NOT apply. Enterprises must evaluate this before linking.

### 摘要
Anthropic 发布 Claude 平台关联计费（Beta），允许 SaaS 开发者将 Claude API 费用直接计入客户的 Claude 控制台账户，无需共享 API 密钥。19 个平台（包括 Asana、Linear、Ramp）已支持接入。**关键合规提示**：请求仍在开发者组织中执行，客户的 IP 白名单、加密密钥和数据留存设置对这些请求不适用，受监管企业需在接入前审慎评估。

### Summary
Anthropic launched Linked Billing in beta on November 17, allowing SaaS developers to pass through Claude API costs to end-customer organisations without sharing API keys. Customers approve each linked platform in the Claude Console, set a monthly spend limit, and can unlink at any time. The developer and customer can each pay per request. Nineteen platforms already support linked billing, including Asana, Linear, and Ramp. The critical enterprise caveat: requests still execute in the platform's organisation — meaning the customer's IP allowlists, customer-managed encryption keys, and data-retention settings do not apply to those requests.

### Main Takeaway
Linked Billing removes API key sharing risk but introduces a data-governance gap: requests run outside the customer's enterprise controls, which is a material compliance concern for regulated entities before linking any third-party platform.

### Relevance to Sunny
⭐⭐⭐ Directly relevant for Sunny's governance framework: if any third-party tools integrated into the bank's Claude deployment use Linked Billing, their requests run in the third-party's Claude organisation — not in the bank's — which means the bank's IP allowlist, key management, and data-residency settings will not govern those calls.
