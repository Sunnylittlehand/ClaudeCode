Claude Code v2.1.222（2026年8月3–4日）新增VSCode Focus模式：通过Ctrl+Alt+F可将工具调用详情折叠为每轮摘要，仅保留实时运行指示器，显著降低视觉噪声。安全方面，修复了bash工具在zsh中通过正则条件执行隐藏命令的权限绕过漏洞，以及孤立Worktree子代理可对主仓库执行破坏性git命令的问题。Google Vertex AI的工具搜索功能已为Claude 4.5及更新版本重新启用。

### Summary
Claude Code v2.1.222 (August 3–4) introduces a VSCode Focus view — a chat-menu toggle (Ctrl+Alt+F) that collapses tool-call activity behind a per-turn expandable summary with a live running-tool indicator, reducing visual noise during long agentic sessions. ### Main Takeaway

### Summary
